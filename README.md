# RestInnov CMS (Laravel 12)

CMS immobilier modulaire orienté production (Core + Modules), sans dépendance WordPress.

## Démarrage rapide
1. `composer install`
2. `cp .env.example .env`
3. `php artisan key:generate`
4. Configurer la base MySQL puis lancer `php artisan migrate --seed`
5. Ouvrir `/install` pour installation web guidée.

Voir `docs/INSTALLATION.md`.
